Settings, calibration and diagnostics
Sensitivity

Assumed 1. Browsers differ (physical, logical or CSS pixels), so use calibration below if turns don't match.

These values are not converted from, or matched to, any game's sensitivity scale.

Crosshair

Your data

Run summaries (score, accuracy, seed) are stored only in this browser. No mouse movement is recorded.

Sound

Short synthesized beeps confirm hits and misses. No game audio is used.

Calibration

Press the arena, turn the mouse a measured distance, press Esc, then apply. The counter above reads the degrees the view actually turned.

Field of view

Your setting is the horizontal FOV measured in a 16:9 window. Vertical FOV is derived from it and stays fixed; wider windows show more to the sides.

Changes the arena's aspect ratio so you can see Hor+ behaviour. Layout only.
